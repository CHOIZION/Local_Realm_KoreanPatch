Local Realm 한글패치 적용 도구 v1.0.0

사용 방법
1. LocalRealm-Korean-Patcher.exe를 실행합니다. Python이나 Node 설치는 필요 없습니다.
2. 게임 경로를 확인합니다. Steam의 다른 라이브러리도 자동으로 찾습니다.
   찾지 못하면 '찾아보기'에서 게임 폴더의 local-realm.exe를 선택합니다.
3. 게임을 완전히 종료하고 '한글패치 적용'을 누릅니다.
4. 완료 후 Steam 또는 '게임 실행' 버튼으로 실행합니다. 언어는 KO를 선택하세요.

기본 포함 번역을 사용하면 번역 파일을 따로 받을 필요가 없습니다.
검수 프로그램에서 수정했다면 '번역 파일 선택…'으로 내보낸 JSON을 선택하고 적용하세요.
게임 실행 중에는 적용하지 않습니다. 패치 결과는 재실행 후 반영됩니다.

원본 복원
'원본으로 복원'을 누르면 지원 버전의 원본 실행 파일로 돌아갑니다.
원본은 게임 폴더의 .localrealm-ko-backup/local-realm.original.exe에 자동 보관됩니다.
이전 도구로 적용한 같은 버전의 패치도 원본을 검증하여 재적용/복원할 수 있습니다.
사용자가 만든 세계관·글·저장 파일은 수정하지 않습니다.

지원 환경
Windows x64용 Local Realm. 게임 버전은 실행 파일 SHA-256으로 확인합니다.
지원 원본: d0bcd19676e59a4febf05daf2089b10cc405bb10a14696c2c12bd63d92aa3484
Steam 업데이트로 실행 파일이 달라지면 새 버전용 패치가 필요합니다.
다른 버전에는 적용하지 않으며 오래된 백업으로 덮어쓰지도 않습니다.

권한 오류
게임을 종료해도 폴더 쓰기 권한 오류가 나면 EXE를 마우스 오른쪽 클릭하여
'관리자 권한으로 실행'하세요. 자동으로 시스템 설정이나 Steam 실행 옵션을 바꾸지 않습니다.

설정/기록
선택한 게임 위치와 오류 기록: %LOCALAPPDATA%\LocalRealmKorean\Patcher
원본 백업과 마지막 적용 기록: 게임 폴더의 .localrealm-ko-backup
네트워크 연결, 계정, API 키가 필요하지 않습니다.
