Local Realm 번역 검수 프로그램 v1.0.0

이 프로그램은 영어와 한국어를 대조하여 다듬고 번역 파일을 만드는 도구입니다.
게임에 실제로 적용할 때에는 별도 LocalRealm-Korean-Patcher.exe를 사용합니다.

1. LocalRealm-Translation-Reviewer.exe를 실행합니다.
2. 목록에서 문구를 선택하고 오른쪽 한국어를 수정합니다.
3. Ctrl+S: 저장. Ctrl+Enter: 검수 완료로 표시하고 다음 문구로 이동.
4. '패치용 번역 내보내기'를 눌러 JSON 파일을 만듭니다.
5. 한글패치 도구에서 '번역 파일 선택…'으로 JSON을 불러오고 적용합니다.

기존 검수 파일 가져오기
'번역 JSON 가져오기'에서 이전 도구의 data/catalog.json 또는 새로 내보낸 JSON을
선택할 수 있습니다. 지원하는 문구 ID/원문 목록이 동일해야 합니다.
CSV 가져오기/내보내기도 지원합니다. 원문과 ID는 유지하세요.

자리표시자와 서식
{name}, {n} 같은 자리표시자와 <code>, <strong> 등의 태그를 유지하세요.
잘못된 자리표시자/태그는 패치용 내보내기 시 차단합니다.
빈 번역은 원문으로 표시됩니다.
'|field key' 등 원문 뒤의 문맥 구분자는 번역에 옮기지 않습니다.
추가 유형·필드·생물군계 문구도 다른 문구와 똑같이 검수할 수 있습니다.

작업 데이터
최초 실행 시 포함된 1,317개 번역을 작업 폴더로 복사합니다.
작업 폴더: %LOCALAPPDATA%\LocalRealmKorean\Reviewer
data/catalog.json: 번역과 검수 상태, 메모
data/qa.json: QA 기록
backups/reviews: 저장 전 번역 백업
EXE를 다른 폴더로 옮기거나 교체해도 작업 폴더는 유지됩니다.
'작업 폴더' 버튼으로 열 수 있습니다. 중요한 검수본은 JSON으로 별도 보관하세요.
프로그램 두 개를 동시에 열어 같은 데이터를 덮어쓰는 것을 막습니다.

QA
영어 문구, 발견 위치, 메모를 기록하고 TXT/CSV/JSON을 가져올 수 있습니다.
기존 원문과 일치하면 연결됩니다. 새로운 문구는 '추가 분석 대상'입니다.
새 문구를 게임에 연결하려면 해당 화면의 코드 위치를 개발자가 확인해야 합니다.

이 도구 자체에는 게임 원본이나 추출한 전체 게임 소스가 들어 있지 않습니다.
게임 설치 없이도 번역을 검수할 수 있습니다. Python, Node, 계정, 인터넷이 필요 없습니다.
